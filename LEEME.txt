PASOS PARA APLICAR ESTOS CAMBIOS (en tu repo real):

1) Copia todos los archivos de este zip sobre tu repo, respetando rutas.
   routes/web.php, database/seeders/RolesPermisosSeeder.php y routes/seguridad.php
   reemplazan por completo a los tuyos (ya incluyen tu contenido original + los cambios).

2) Borra estos archivos, ya no se usan:
   - app/Domain/                                        (carpeta completa)
   - app/Http/Controllers/Ingenierias/ProyectoController.php
   - routes/roles.php   (fue renombrado a routes/seguridad.php, mismo contenido)

3) Corre:
   php artisan migrate:fresh --seed
   php artisan wayfinder:generate --with-form --no-interaction
   npm run dev   (o npm run build)

NOTA: Los route names de Roles (roles.index, roles.show, etc.) NO cambiaron,
solo el archivo .php que los contiene y su require en web.php. Por eso el
import `@/routes/roles` en resources/js/pages/roles/Show.vue sigue funcionando
sin cambios.
